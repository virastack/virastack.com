<h2 id="kalite">Kalite</h2>

<div className="overflow-x-auto rounded-lg border border-border">
  <table>
    <thead>
      <tr><th>Komut</th><th>Ne zaman kullan</th></tr>
    </thead>
    <tbody>
      <tr><td>`pnpm lint`</td><td>Önbellekli ESLint. Kod yazarken erken yakalamak için.</td></tr>
      <tr><td>`pnpm lint:fix`</td><td>ESLint sorunlarını otomatik düzeltir, ardından Prettier yazar.</td></tr>
      <tr><td>`pnpm lint:ci`</td><td>CI için katı lint: sıfır uyarı + Prettier check. GitHub Actions ile aynı kapı.</td></tr>
      <tr><td>`pnpm format`</td><td>Tüm repoyu Prettier ile formatlar.</td></tr>
      <tr><td>`pnpm format:check`</td><td>Dosya yazmadan format kontrolü (CI dostu).</td></tr>
      <tr><td>`pnpm typecheck`</td><td>tsc --noEmit ile TypeScript kontrolü. Tip değiştirdiysen push öncesi çalıştır.</td></tr>
      <tr><td>`pnpm knip`</td><td>Kullanılmayan dosya, export ve bağımlılıkları bulur. Şablonu sade tutar.</td></tr>
      <tr><td>`pnpm test`</td><td>Test paketini Vitest ile bir kez çalıştırır. CI bunu build’den önce çalıştırır.</td></tr>
      <tr><td>`pnpm test:watch`</td><td>Kod yazarken Vitest’i izleme modunda çalıştırır.</td></tr>
    </tbody>
  </table>
</div>

Husky commit’te lint-staged, push’ta ilgili kontrolleri çalıştırır. CI yerelde kırılmadıkça tam suite’i elle koşman nadiren gerekir.
