<h2 id="kullanim">Usage</h2>

Run the CLI interactively, or pass flags for a silent install. Prefer a guided flow? Use the [Builder](/start/builder).

<CodeBlockCommand {...convertNpmCommand("npx virastack@latest")} />

<h2 id="add">add command</h2>

To add a ViraStack tool to an existing project, run the `add` command from the project root:

<CodeBlockCommand {...convertNpmCommand("npx virastack@latest add mask")} />

<CodeBlockCommand {...convertNpmCommand("npx virastack@latest add password")} />

<CodeBlockCommand {...convertNpmCommand("npx virastack@latest add address")} />

<CodeBlockCommand {...convertNpmCommand("npx virastack@latest add ai --agent cursor")} />

Available tools:

- `mask`: installs `@virastack/mask`
- `password`: installs `@virastack/password`
- `address`: installs `@virastack/address`
- `ai`: runs `@virastack/ai init` (with `--agent` when given). Files you changed are kept.

During `init`, `mask`, `password` and `address` are optional; AI rules and design skills are added automatically. Use `add` for a tool you skipped or for an existing app. Outside Start projects, run [ViraStack AI](/ai/docs/installation) directly.

<h2 id="telemetry">Telemetry</h2>

ViraStack collects anonymous usage data so we can keep statistics (for example template, i18n preference, selected tools and AI coding tools, package manager, and CLI version). No personal data, project name, or file paths are collected.

If you prefer not to share this data:

<CodeBlockCommand {...convertNpmCommand("npx virastack@latest --telemetry-disable")} />
