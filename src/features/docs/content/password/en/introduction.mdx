Password fields are easy to get wrong: missing ARIA, a toggle that submits the form, a password manager that sees a text field, rules that differ between the form and the server. `useViraPassword()` handles this in one hook. Markup and styling stay yours.

<h2 id="peer">Requirements</h2>

- <AcademyBadge kind="react" label="React 18.2+" /> and `react-dom` (React 19 supported)
- No runtime dependencies
- <AcademyBadge kind="react-hook-form" /> is optional; any form library or none works.

Also selectable during <GuideProductMark id="start" linked={false}>Start</GuideProductMark> CLI setup (`npx virastack@latest --tools password`).

<h2 id="neden">Why <GuideProductMark id="password" linked={false} tone="heading">Password</GuideProductMark>?</h2>

- **Headless**: every returned value is a valid input or button prop.
- **Radix-level details**: hides on submit, focus returns after a click, controlled `visible`, Caps Lock, `autoComplete`.
- **NIST-style strength**: length first (15–64), common passwords, repeats and personal info. No composition rules by default.
- **Same rules on the server**: one policy object for the form and the Server Action.
- **Error keys**: `password.tooShort`, `password.mismatch`… Messages and i18n stay yours.
