<h2 id="merge">Prop merging</h2>

Your `inputProps` and `btnProps` are applied after the hook's, so most keys can be overridden. These are combined instead:

```tsx
useViraPassword({
  inputProps: { onBlur: () => track("blur"), className: "pr-10" },
})
// onBlur: the hook's handler runs first, then yours
// className, aria-describedby: joined with a space
// ref (your own): passed through
```

The returned `inputProps` holds attributes only, so it can be spread before or after `register()` or a [ViraStack Mask](/password/docs/react-hook-form) field without replacing their ref or handlers.
