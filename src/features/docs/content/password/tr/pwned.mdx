<h2 id="kullanim">Kullanım</h2>

Sen çağırmadıkça kapalıdır. Ücretsiz Pwned Passwords range API'sini kullanır; anahtar ve bağımlılık gerekmez.

<PasswordExamplePreview id="pwned" />

```ts
checkPwned(password, {
  signal,         // AbortSignal
  timeout: 3000,  // ms, varsayılan 5000
  fetch,          // özel fetch (test, proxy)
})
```

Kayıtta bunun yerine `validatePassword`'a `pwned` ver: politikayı ve sızıntı listesini tek çağrıda kontrol eder, istek yalnızca politika geçince gider. Bkz. [sunucu doğrulaması](/password/docs/server#sizinti).

<h2 id="gizlilik">Gizlilik ve sınırlar</h2>

- Parolanın SHA-1 özetinin yalnızca ilk 5 karakteri gönderilir; parola ve tam özet asla çıkmaz. Yanıtlar dolgu (padding) içerir.
- Sunucudan çağır. Tarayıcıdan çağrılırsa Have I Been Pwned kullanıcının IP'sini görür.
- `crypto.subtle` yalnızca HTTPS ve localhost'ta vardır; aksi halde sonuç `unknown` olur.
- Her tuş vuruşunda çağırma; gönderimde kontrol et.
