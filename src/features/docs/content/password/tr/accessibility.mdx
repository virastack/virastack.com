<h2 id="aria">ARIA öznitelikleri</h2>

```html
<input id="virapassword-input-:r0:" type="password" aria-describedby="…-strength" />
<button
  type="button"
  aria-label="Toggle password visibility"
  aria-pressed="false"
  aria-controls="virapassword-input-:r0:"
/>
```

- `type="button"`: toggle formu asla göndermez.
- `aria-pressed` ekran okuyucuya parolanın görünüp görünmediğini söyler; `aria-controls` butonu input'a bağlar.
- Etiket İngilizcedir; btnProps ile çevir:

```tsx
useViraPassword({ btnProps: { "aria-label": t("togglePassword") } })
```

<h2 id="odak">Odak</h2>

- Fare veya dokunmayla basınca odak ve imleç input'a döner.
- Odaktaki butonda Enter veya Space odağı butonda tutar.
- Safari, "Tüm denetimlere Sekme" açık değilse Tab ile butonları atlar; Option+Tab ulaşır. Bu bir tarayıcı ayarıdır, hata değil.

<h2 id="canli">Canlı bölge</h2>

`strengthProps`'u gücü gösteren elemana spread et. Her kuralı değil kısa bir seviyeyi duyur; yazarken gürültü olmasın.

```tsx
const { inputProps, strength, strengthProps } = useViraPassword({ policy })

<input {...inputProps} />
<p {...strengthProps}>{strength?.level}</p>
// role="status" aria-live="polite" aria-atomic="true"
// input, ona işaret eden aria-describedby alır
```

<h2 id="caps">Caps Lock</h2>

`capsLock`, input odaktayken Caps Lock açıksa true olur. Metinle uyar; tek başına renk yeterli değildir.

<h2 id="ids">Stabil ID'ler</h2>

`id` verilmezse input id'sini server ve client'ta eşleşen `useId()`'den alır. Etiket veya test sabit bir değer istiyorsa `id` ver.
