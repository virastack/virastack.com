<h2 id="temel">Temel kullanım</h2>

Ayrı bir hook yoktur. Tekrar alanına `matchWith` ver: `matches` `true`, `false` veya alan boşken `null` olur. İki değer sunucudaki gibi NFKC sonrası karşılaştırılır.

<PasswordExamplePreview id="confirm" />

<h2 id="rule">rule</h2>

`rule.validate` her zaman en son `matchWith`'i okur; aynı nesne `register()`'a verilebilir. Parola değişince tekrar alanını yeniden kontrol etmek için [deps](/password/docs/react-hook-form)'e bak.

```tsx
const password = useWatch({ control: form.control, name: "password" })
const { inputProps, rule } = useViraPassword({ matchWith: password })

<input {...inputProps} {...form.register("confirm", rule)} />
// değerler farklıysa "password.mismatch" (boş tekrar alanı da geçmez)
```

<h2 id="gorunurluk">Ortak görünürlük</h2>

Her alanın kendi toggle'ı vardır. İkisini birlikte göstermek için tek state ile kontrol et:

```tsx
const [visible, setVisible] = useState(false)

const shared = { visible, onVisibleChange: setVisible }

const passwordField = useViraPassword(shared)
const confirmField = useViraPassword({ ...shared, matchWith: password })
```
