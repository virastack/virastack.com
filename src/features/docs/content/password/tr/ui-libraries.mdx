`useViraPassword()` prop bag döndürür. Input ve butona doğrudan spread et; ikon `btnProps.children` içindedir.

Paket yalnızca görünürlük mantığını ve erişilebilir props’ları yönetir; markup ve stil sana aittir. shadcn/Tailwind, Ant Design (kendi CSS’i + `style`/`className`) veya Chakra (style props) fark etmez; aynı hook her UI kitine bağlanır.

<h2 id="pattern">Ortak pattern</h2>

```tsx
const { inputProps, btnProps } = useViraPassword({
  inputProps: { className: "pr-10" },
  btnProps: { className: "absolute inset-y-0 right-2 my-auto" },
})

return (
  <div className="relative">
    <input {...inputProps} placeholder="Parola" />
    <button {...btnProps} />
  </div>
)
```

<h2 id="ant-design" className="flex items-center gap-2.5"><AntDesignDarkTheme className="size-5 shrink-0" aria-hidden />Ant Design</h2>

`antd` native props kabul eder. Aynı pattern:

```tsx
import { useViraPassword } from "@virastack/password"
import { Input, Button } from "antd"

function Example() {
  const { inputProps, btnProps } = useViraPassword()
  const { children, ...restBtn } = btnProps

  return (
    <div style={{ position: "relative" }}>
      <Input {...inputProps} placeholder="Parola" />
      <Button {...restBtn} type="text" style={{ position: "absolute", right: 4, top: "50%", transform: "translateY(-50%)" }}>
        {children}
      </Button>
    </div>
  )
}
```

<h2 id="chakra" className="flex items-center gap-2.5"><ChakraUi className="size-5 shrink-0" aria-hidden />Chakra UI</h2>

Chakra `Input` / `IconButton` ile de çalışır:

```tsx
import { useViraPassword } from "@virastack/password"
import { Input, IconButton, Box } from "@chakra-ui/react"

function Example() {
  const { inputProps, btnProps } = useViraPassword()
  const { children, ...restBtn } = btnProps

  return (
    <Box position="relative">
      <Input {...inputProps} placeholder="Parola" pe="10" />
      <IconButton
        {...restBtn}
        aria-label={restBtn["aria-label"] ?? "Toggle password visibility"}
        position="absolute"
        right="2"
        top="50%"
        transform="translateY(-50%)"
        variant="ghost"
        size="sm"
      >
        {children}
      </IconButton>
    </Box>
  )
}
```
