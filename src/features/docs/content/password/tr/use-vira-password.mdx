<h2 id="merge">Prop merging</h2>

`inputProps` ve `btnProps` hook'unkilerden sonra uygulanır; çoğu anahtar değiştirilebilir. Şunlar birleştirilir:

```tsx
useViraPassword({
  inputProps: { onBlur: () => track("blur"), className: "pr-10" },
})
// onBlur: önce hook'un handler'ı, sonra sizinki
// className, aria-describedby: boşlukla birleşir
// ref (sizinki): olduğu gibi geçer
```

Dönen `inputProps` yalnızca öznitelik taşır; `register()` veya bir [ViraStack Mask](/password/docs/react-hook-form) alanından önce ya da sonra spread edilebilir, onların ref ve handler'larını ezmez.
