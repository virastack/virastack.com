<h2 id="form">useViraPassword(form)</h2>

`useViraMask(form, schema)` gibi önce formu ver. Her alan için bir giriş yaz: anahtar alan adıdır (farklıysa `name` ver), `matchWith` ve `forbidden` alan adı alır, `rules` ise `required` gibi ek React Hook Form kuralları ekler.

Her alan kuralıyla kaydedilir. Değerler formdan okunur, bu yüzden `reset()` ve `setValue()` takip edilir. Kullanıcı alandan çıktıktan ya da formu gönderdikten sonra, bağlı olduğu alan değişince alan yeniden kontrol edilir (tekrar alanı parolayla, parola e-postayla). `value`, `deps` veya `trigger` gerekmez.

```tsx
import { useViraPassword } from "@virastack/password"

const { password, confirm } = useViraPassword(form, {
  password: { policy, forbidden: ["email"] }, // alan adları
  confirm: { matchWith: "password" },
})

<input {...password.inputProps} /> // register() zaten içinde
<button {...password.btnProps} />
<input {...confirm.inputProps} />
```

`react-hook-form` isteğe bağlı bir peer'dır (7.55+): hook yalnızca tiplerini ve verdiğin formun metotlarını kullanır, formsuz `useViraPassword()` eskisi gibi çalışır. Bir input'u ViraStack Mask alanıyla ya da bir resolver ile paylaşacaksan hook'u aşağıdaki gibi kendin bağla.

<h2 id="register">register()</h2>

```tsx
const { inputProps, btnProps, rule } = useViraPassword({ policy, value: password })

// inputProps yalnızca öznitelik taşır: register()'dan önce ya da sonra spread et
<input {...inputProps} {...form.register("password", rule)} />
<button {...btnProps} />
```

<h2 id="value">useWatch()</h2>

`reset()` ve `setValue()` input olayı tetiklemeden değeri değiştirir. Güç ve `matches` bunları takip etsin diye `value` ver. `useWatch`, `watch()`'tan farklı olarak React Compiler ile de çalışır.

```tsx
const password = useWatch({ control: form.control, name: "password" })
const { inputProps, strength } = useViraPassword({ policy, value: password })
```

<h2 id="rule">rule & deps</h2>

`rule` ilk hata anahtarını döndürür. `deps`, parola değişince tekrar alanını yeniden doğrular.

```tsx
form.register("password", { ...rule, deps: ["confirm"] })

// deps yalnızca kullanıcı girişinde çalışır. setValue'dan sonra tekrar alanını sen kontrol et:
form.setValue("password", next)
form.trigger("confirm")
```

Forma `method="post"` ver. Hydration'dan önce form yerel olarak gönderilir ve varsayılan GET parolayı URL'ye yazar.

<h2 id="controller">Controller</h2>

```tsx
<Controller
  control={form.control}
  name="password"
  render={({ field }) => <PasswordField field={field} />}
/>

function PasswordField({ field }: { field: ControllerRenderProps<Values, "password"> }) {
  const { inputProps } = useViraPassword({
    policy,
    value: field.value,
    inputProps: { ...field, onChange: (e) => field.onChange(e.target.value) },
  })
  return <input {...inputProps} />
}
```
