A Turkish address is picked in three steps, each depending on the one before: the province, then a district inside it, then a neighbourhood inside that. The postal code belongs to the neighbourhood. `useViraAddress()` runs that chain for you, loads the data a province at a time and works out the postal code. The markup and the styling stay yours.

Picking a province lists its districts. Picking a district lists its neighbourhoods, which are fetched for that province the first time it is needed. Picking a neighbourhood fills in `value.postalCode`. Changing any level clears everything below it. Typing a postal code works the other way round and fills in the selects.

The demo above runs the same hook on <AcademyBadge kind="shadcn" /> selects; see [UI libraries](/address/docs/ui-libraries) for other components.

<h2 id="neden">Why <GuideProductMark id="address" linked={false} tone="heading">Address</GuideProductMark>?</h2>

- **Chained selection**: Province, district, neighbourhood. Changing a level clears the ones below it, in the hook and in your form.
- **Postal code both ways**: Picking a neighbourhood fills in its code, and typing a code fills in the selects: all three when the code has one neighbourhood, province and district otherwise. See [from a postal code](/address/docs/postal-code).
- **One-line address**: `formatAddress` turns the pick into "Alandüzü Mah. Adapazarı/Sakarya", optionally with the postal code.
- **Up-to-date data**: An automated check compares the dataset against PTT every month. When something changes, a patch release ships; the API stays the same.
- **Loaded on demand**: Province and district names ship with the package; a province's neighbourhoods download only when it is picked. A typical visit costs about 10 kB.
- **Headless**: Nothing is rendered for you. A native select, <AcademyBadge kind="shadcn" />, <AcademyBadge kind="ant-design" /> or your own component all work.
- **Turkish-aware**: Sorting, casing and search handle the dotted `İ` and the dotless `ı` correctly.
- **Validated on the server**: A postal code sent by the client is never trusted; `resolveAddress` checks the address against the dataset, derives the code itself and refuses a submitted code that does not match.

<p className="text-sm text-muted-foreground">**How size was measured:** The same form (chained province, district and neighbourhood selects) was written with each package and built with esbuild in production mode, minified, tree-shaken and code split. The size is the gzip difference in the JS loaded on first visit over the same form built without a data package, so <AcademyBadge kind="react" />, present on both sides, is not counted. With Address, a province’s neighbourhoods load when it is picked: 4.8 KB median, 29.6 KB at most. turkey-location-data reads its data with Node’s `fs` module, so it does not build for the browser. Partial server validation means the address can be checked by hand against the exported lists.</p>
