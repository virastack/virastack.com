<h2 id="temel">Basic usage</h2>

The hook returns three lists and three setters. Every list item is `{ value, label }`: `value` is the name as the dataset spells it (`FATİH`), `label` is the display form (`Fatih`). For provinces, `value` is the plate code (`"34"`).

```tsx
const {
  provinces, districts, neighbourhoods,
  setProvince, setDistrict, setNeighbourhood,
  value, loading,
} = useViraAddress()

return (
  <>
    <select
      value={value.provinceCode ?? ""}
      onChange={(e) => setProvince(e.target.value)}
    >
      <option value="">Select a province</option>
      {provinces.map((p) => (
        <option key={p.value} value={p.value}>{p.label}</option>
      ))}
    </select>

    <select
      value={value.district ?? ""}
      onChange={(e) => setDistrict(e.target.value)}
      disabled={!districts.length}
    >
      <option value="">Select a district</option>
      {districts.map((d) => (
        <option key={d.value} value={d.value}>{d.label}</option>
      ))}
    </select>

    <select
      value={value.neighbourhood ?? ""}
      onChange={(e) => setNeighbourhood(e.target.value)}
      disabled={!neighbourhoods.length}
    >
      <option value="">
        {loading.neighbourhoods ? "Loading…" : "Select a neighbourhood"}
      </option>
      {neighbourhoods.map((n) => (
        <option key={n.value} value={n.value}>{n.label}</option>
      ))}
    </select>
  </>
)
```

The [prop getters](/address/docs/ui-libraries) do the same wiring in one line. `setProvince` accepts the plate code as a number or a string.

<h2 id="value">value</h2>

Everything your form needs, in one object:

```ts
{
  provinceCode: "34",       // plate code, as a string
  province: "İSTANBUL",
  district: "FATİH",
  neighbourhood: "AKSARAY MAH.",
  postalCode: "34096",      // the neighbourhood's first code, or the one typed
  postalCodes: ["34096"],   // all of them; a few hundred have several
}
```

Levels that are not picked yet are `null`, and `postalCodes` is an empty array. Names are upper case, as the dataset stores them; show the `label` from the lists, or run them through [formatName](/address/docs/helpers).

<h2 id="kaynak">Your own data source</h2>

By default the lists come from the bundled dataset. Pass a `source` to use a small fixture in tests, or to read the lists from your own API:

```tsx
import { useViraAddress, type AddressSource } from "@virastack/address"

const aksaray = {
  name: "AKSARAY MAH.",
  postalCode: "34096",
  postalCodes: ["34096"],
}

const source: AddressSource = {
  provinces: [
    { code: 34, name: "İSTANBUL", districts: ["FATİH", "KADIKÖY"] },
  ],
  neighbourhoods: async (code) => new Map([["FATİH", [aksaray]]]),
}

const address = useViraAddress({ source })
```

The hook only reads neighbourhoods when the province changes, so passing a new `source` object on every render does not reload anything. If you only want the neighbourhoods to come from elsewhere, `setLoader` is shorter; see the [dataset](/address/docs/data).
