<h2 id="temel">Temel kullanım</h2>

Hook üç liste ve üç setter döndürür. Her liste `{ value, label }` biçimindedir: `value` veri setindeki ham adı (`FATİH`), `label` başlık biçimini (`Fatih`) taşır. İl listesinde `value` plaka kodudur (`"34"`).

```tsx
const {
  provinces, districts, neighbourhoods,
  setProvince, setDistrict, setNeighbourhood,
  value, loading,
} = useViraAddress()

return (
  <>
    <select
      value={value.provinceCode ?? ""}
      onChange={(e) => setProvince(e.target.value)}
    >
      <option value="">İl seç</option>
      {provinces.map((p) => (
        <option key={p.value} value={p.value}>{p.label}</option>
      ))}
    </select>

    <select
      value={value.district ?? ""}
      onChange={(e) => setDistrict(e.target.value)}
      disabled={!districts.length}
    >
      <option value="">İlçe seç</option>
      {districts.map((d) => (
        <option key={d.value} value={d.value}>{d.label}</option>
      ))}
    </select>

    <select
      value={value.neighbourhood ?? ""}
      onChange={(e) => setNeighbourhood(e.target.value)}
      disabled={!neighbourhoods.length}
    >
      <option value="">
        {loading.neighbourhoods ? "Yükleniyor…" : "Mahalle seç"}
      </option>
      {neighbourhoods.map((n) => (
        <option key={n.value} value={n.value}>{n.label}</option>
      ))}
    </select>
  </>
)
```

Elle bağlamak istemiyorsan aynı şeyi [prop getter'lar](/address/docs/ui-libraries) tek satırda yapar. `setProvince` plaka kodunu sayı veya metin olarak alır.

<h2 id="value">value</h2>

Formun ihtiyaç duyduğu her şey tek nesnededir:

```ts
{
  provinceCode: "34",       // plaka kodu, string olarak
  province: "İSTANBUL",
  district: "FATİH",
  neighbourhood: "AKSARAY MAH.",
  postalCode: "34096",      // mahallenin ilk posta kodu ya da yazılan kod
  postalCodes: ["34096"],   // hepsi; birkaç yüz mahallede birden fazla
}
```

Seçilmemiş seviyeler `null`, `postalCodes` boş dizidir. Adlar veri setindeki gibi büyük harflidir; ekranda göstermek için listelerdeki `label` alanını ya da [formatName](/address/docs/helpers) kullan.

<h2 id="kaynak">Kendi veri kaynağın</h2>

Varsayılan kaynak paketteki veri setidir. Testlerde küçük bir fixture kullanmak ya da listeleri kendi API'nden okumak için `source` ver:

```tsx
import { useViraAddress, type AddressSource } from "@virastack/address"

const aksaray = {
  name: "AKSARAY MAH.",
  postalCode: "34096",
  postalCodes: ["34096"],
}

const source: AddressSource = {
  provinces: [
    { code: 34, name: "İSTANBUL", districts: ["FATİH", "KADIKÖY"] },
  ],
  neighbourhoods: async (code) => new Map([["FATİH", [aksaray]]]),
}

const address = useViraAddress({ source })
```

Hook mahalleleri yalnızca il değiştiğinde okur; her render'da yeni bir `source` nesnesi vermek yüklemeyi tekrarlatmaz. Yalnızca mahallelerin nereden geldiğini değiştirmek istiyorsan `setLoader` daha kısadır; bkz. [veri seti](/address/docs/data).
