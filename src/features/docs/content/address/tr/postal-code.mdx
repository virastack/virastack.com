`getPostalCodeInputProps()` düz bir `<input>`'a yayılır: `inputMode="numeric"`, `autoComplete="postal-code"`, `maxLength` 5, `value` ve `onChange`. Rakam olmayan her şey atılır; arama beş rakam girilince yapılır. Daha az rakamla düzenlerken adres yerinde kalır.

<h2 id="kesinlik">Ne kadar kesin?</h2>

Her posta kodu tek bir ilçeye aittir ve ilk iki hanesi ilin plaka kodudur. Ama bir kod çoğu zaman birden çok mahalleyi kapsar: 2.777 kodun yalnızca 205'inin altında tek mahalle vardır, Sakarya'da `54100` ise 81 mahallenin ortak kodudur. <h2 id="davranis">Davranış</h2>

- İl veya ilçe elle seçilince arama bırakılır: mahalle listesi yeniden tamamlanır, input seçimden türetilen kodu gösterir.
- Daraltılmış listeden mahalle seçmek aramayı korur. Birden çok kodu olan bir mahallede `value.postalCode` kullanıcının yazdığı koddur, ilki değil.
- Kod yüklenirken başka bir seçim yapılırsa ya da yeni bir kod yazılırsa eski yanıt yenisinin üstüne yazılmaz.
- İl seçim için zaten yüklendiyse tekrar indirilmez; arama aynı veriyi kullanır.
- `form` verildiyse dolan her seviye forma `shouldDirty` ile yazılır; `"partial"` durumda mahalle boş, posta kodu dolu olur. `form.reset()` aramayı da bırakır.

<h2 id="set-postal-code">setPostalCode()</h2>

Input kullanmadan, örneğin kayıtlı bir adresten ya da konumdan gelen kodla aramayı kendin başlat. Promise, bulunan durumla çözülür:

```ts
const { setPostalCode, value } = useViraAddress()

await setPostalCode("34710") // "exact"
value
// { province: "İSTANBUL", district: "KADIKÖY",
//   neighbourhood: "CAFERAĞA MAH.", postalCode: "34710", ... }

await setPostalCode("34096") // "partial"
value
// { province: "İSTANBUL", district: "FATİH",
//   neighbourhood: null, postalCode: "34096", ... }

await setPostalCode("34999") // "unknown": adres değişmez
await setPostalCode(null)    // null: arama bırakılır, adres kalır
```

Kodu metin olarak ver: `01040` sayı olarak `1040` olur ve baştaki sıfır geri getirilemez. Boşluklar atılır, `"34 710"` çalışır.

<h2 id="ui">UI kütüphaneleri</h2>

Prop'lar standart input prop'larıdır; `onChange` hem olayı hem düz değeri alır. shadcn/ui ve Ant Design'ın `Input`'u olduğu gibi kabul eder:

```tsx
import { Input } from "@/components/ui/input"

<Input
  {...address.getPostalCodeInputProps({ placeholder: "34710" })}
  aria-describedby="postal-code-hint"
/>
```
