<pre><code>{output}</code></pre>

- `+` created
- `~` updated

<h2 id="examples">Examples</h2>

See what would change, without writing:

<CodeBlockCommand {...convertNpmCommand("npx @virastack/ai init --dry-run")} />

Install for Cursor only:

<CodeBlockCommand {...convertNpmCommand("npx @virastack/ai init --agent cursor")} />

Force the TanStack Start rules:

<CodeBlockCommand {...convertNpmCommand("npx @virastack/ai init --framework tanstack")} />

Remove ViraStack AI from the project:

<CodeBlockCommand {...convertNpmCommand("npx @virastack/ai remove")} />

<h2 id="ci">CI and scripts</h2>

In a non-interactive shell the CLI never asks. Changed files are skipped with a warning, and `--yes` behaves the same in a terminal. Pass `--force` only when you want your changes replaced; see [customization](/ai/docs/customization).
