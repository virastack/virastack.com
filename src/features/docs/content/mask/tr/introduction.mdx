<h2 id="neden">Neden <GuideProductMark id="mask" linked={false} tone="heading">Mask</GuideProductMark>?</h2>

- **<AcademyBadge kind="react-hook-form" /> için**: tek doğruluk kaynağı formdur; hook kendi değer state'i tutmaz.
- **Türkiye'ye hazır**: TCKN, VKN, TR IBAN, TR telefon ve kuruşu koruyan TRY.
- **Tip güvenli**: alan adları, `from` ve kurallar form tipinden denetlenir; yazım hatası derleme hatasıdır.
- **Sunucuda da**: aynı şema `@virastack/mask/server` ile Server Action'da ayrıştırılır ve doğrulanır.
- **Kenara çekilir**: UI paketi değildir; <AcademyBadge kind="shadcn" />, Radix ya da düz input ile çalışır.
