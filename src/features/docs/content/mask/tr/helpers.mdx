<h2 id="create-mask">createMask</h2>

Hook'un kullandığı nesnenin aynısı. Listelerde, tablolarda ve raporlarda maskeli gösterim için `format`; dışarıdan gelen metin için `parse`.

```ts
import { createMask } from "@virastack/mask"

const phone = createMask({ preset: "phone", country: "TR" })
phone.format("5551234567")        // "(555) 123 45 67"
phone.parse("+90 555 123 45 67")  // "5551234567"
phone.validate("555")             // "phone.incomplete"
phone.isComplete("5551234567")    // true

const price = createMask("currency")
price.format("1234.5", { from: "USD" }) // "$1,234.5"
```

<h2 id="validators">Doğrulayıcılar</h2>

```ts
import {
  getCardType,
  isValidCard,
  isValidIBAN,
  isValidLuhn,
  isValidPlate,
  isValidTCKN,
  isValidVKN,
} from "@virastack/mask"

getCardType("3782 822463 10005") // "amex"
isValidCard("4111111111111111")  // true: uzunluk + Luhn
isValidTCKN("10000000146")       // true
isValidVKN("1234567890")         // true
isValidIBAN("DE89 3704 0044 0532 0130 00") // true, her ülke
isValidIBAN("TR330006100519786457841326")  // true
isValidIBAN("TR33000610051978645784132")   // false: TR IBAN 26 karakter olmalı
isValidPlate("34 ABC 123")      // true: il kodu 01–81 ve resmî harf/rakam grupları
isValidPlate("34 AB 12")        // false: 2 harften sonra 3–4 rakam
```

`isValidPlate` ve `plate` preset'i kuralları [Araçların Satış, Devir ve Tescil Hizmetlerinin Yürütülmesi Hakkında Yönetmelik](https://www.mevzuat.gov.tr/anasayfa/MevzuatFihristDetayIframe?MevzuatTur=7&MevzuatNo=24356&MevzuatTertip=5)'in 34. maddesinden alır: il kodu 01–81, ardından 1 harf ve 4–5 rakam, 2 harf ve 3–4 rakam ya da 3 harf ve 2–3 rakam. Yönetmelik hiçbir Latin harfini hariç tutmaz; Q, W ve X geçer, Türkçe harfler geçmez. Ad, soyad veya unvan içeren plakalar (madde 37) ve özel tahsisli plakalar (madde 36) kontrol edilmez.

Bir Türkiye IBAN'ının hangi bankaya ait olduğunu bulmak için [getTurkishBank](/mask/docs/banks) kullan. Test ve seed verisinde geçerli TCKN ve IBAN için [test verisi](/mask/docs/testing) sayfasına bak.

<h2 id="money">Para</h2>

`toMinorUnits` ondalık metni tam sayı küçük birime çevirir. İkinci argüman ondalık basamak sayısı ya da ISO para kodudur.

```ts
import { toMinorUnits } from "@virastack/mask"

toMinorUnits("1234.56", "TRY") // 123456
toMinorUnits("0.1", 2)         // 10 (float hatası yok)
toMinorUnits("1500", "JPY")    // 1500
```
