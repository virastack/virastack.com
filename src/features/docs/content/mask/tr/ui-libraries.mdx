Dönen nesneyi input'a spread et. Bileşen `ref`'i gerçek `<input>`'a iletmelidir (<AcademyBadge kind="react" label="React 19" />'da prop olarak, <AcademyBadge kind="react" label="React 18" />'de `forwardRef` ile). `value` verme; input kontrolsüzdür.

<h2 id="pattern">Ortak kalıp</h2>

```tsx
const { card } = useViraMask(form, { card: "card" })

// ekranda: "4111 1111 1111 1111"
// form.watch("card"): "4111111111111111"

return <input {...card} placeholder="0000 0000 0000 0000" />
```

```tsx
// Kendi ref'in de lazımsa ikisini birleştir
const inputRef = useRef<HTMLInputElement>(null)

<Input
  {...card}
  ref={(el) => {
    card.ref(el)
    inputRef.current = el
  }}
/>
```
