<h2 id="dinamik">Dinamik maske</h2>

Dizi verirsen değeri bütünüyle alan ilk desen seçilir. Fonksiyon değeri ve `ctx.from` (bağlı alanın değeri) ile desen döner.

```tsx
useViraMask(form, {
  // ilk uyan desen seçilir
  code: { mask: ["999-999", "9999-9999"] },
  // değere ya da bağlı alana göre desen
  card: {
    mask: (value) => (/^3[47]/.test(value) ? "9999 999999 99999" : "9999 9999 9999 9999"),
  },
  // yazılanı desene yerleştirmeden önce düzelt
  phone: { mask: "(999) 999 99 99", normalize: (value) => value.replace(/^0+/, "") },
})
```

<h2 id="sayi-tarih">Sayı, para ve tarih</h2>

`mask`, `number`, `currency` ve `date` birbirini dışlar; ikisini birden vermek derleme hatasıdır.

- `number`: `min`, `max`, `scale` (ondalık basamak), `signed`, `locale` (varsayılan `en-US`; Türkçe ayırıcılar için preset ile `country: "TR"`). Max yazarken, min alan terk edilince uygulanır. `signed` alanda negatif max da alan terk edilince uygulanır.
- `currency`: ISO kodu ya da `{ code, locale, min, max, scale }`. Ayırıcılar ve sembol Intl'den gelir. Kod yoksa sembolsüz `1,234.56`; Türk lirası için `{ preset: "currency", country: "TR" }`.
- `date`: `format`, `min`, `max` (`"today"`, ISO ya da `Date`), `minAge`. Tam tarihlerde form değeri ISO'dur.

<h2 id="preset">definePreset</h2>

Ekibinin maskesini tek yerde tanımla. Ad, hata anahtarlarının önekidir (`orderNo.incomplete`). Hook, sunucu ve testler aynı nesneyi kullanır.

```tsx
// masks.ts — client ve server paylaşır
import { definePreset } from "@virastack/mask/server"

export const orderNo = definePreset("orderNo", {
  mask: "aa-9999",
  transform: "uppercase",
  validate: (value) => !value.startsWith("XX") || "orderNo.reserved",
})

// form
useViraMask(form, { orderNo, returnNo: { preset: orderNo } })
```
