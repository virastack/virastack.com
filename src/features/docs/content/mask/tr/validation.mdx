`<ad>` preset adıdır; özel desende `mask`, `definePreset` ile verdiğin ad.

`iban` preset'i 2.4 ile nedeni ayrı anahtarlarla söyler. `iban.invalid` yedek anahtar olarak kalır: IBAN'da olamayacak bir karakterde (A–Z dışı harf) ve `false` dönen kendi `validate` fonksiyonunda gelir. Mesaj haritanda yalnızca `iban.invalid` varsa üç yeni anahtarı ekle ya da diğer `iban.*` anahtarlarında ona düş. `{ preset: "iban", country: "TR" }` ülkeyi ve uzunluğu sabitlediği için yeni anahtarlardan yalnızca `iban.checksum` döner. Kayıt listesinde olmayan bir ülke kodu reddedilmez; 15–34 karakter ve mod-97 ile kontrol edilir.

```ts
const messages: Record<string, string> = {
  "iban.incomplete": "IBAN eksik",
  "iban.country": "IBAN ülke koduyla başlamalı",
  "iban.length": "IBAN uzunluğu ülkesine uymuyor",
  "iban.checksum": "IBAN hatalı, hanelerini kontrol et",
  "iban.invalid": "Geçersiz IBAN",
}

const text = (key: string) => messages[key] ?? (key.startsWith("iban.") ? messages["iban.invalid"] : key)
```

<h2 id="ozel">Özel doğrulama</h2>

`validate` yerleşik kontrollerden sonra çalışır. Preset üzerinde verirsen ikisi birlikte uygulanır.

```tsx
useViraMask(form, {
  // true: geçerli · false: "<ad>.invalid" · metin: kendi anahtarın
  tckn: { preset: "tckn", validate: (value) => value !== "11111111110" || "tckn.blocked" },
  // React Hook Form kuralları da çalışır
  phone: { preset: "phone", country: "TR", rules: { required: "required", validate: { mobile: (v) => v.startsWith("5") || "phone.mobile" } } },
})
```

<h2 id="resolver">Zod, Valibot ve resolver</h2>

<AcademyBadge kind="react-hook-form" />, resolver varken `register` doğrulamasını atlar. Resolver'ı `maskResolver` ile sar; şema hataları ve maske hataları birlikte gelir. Sarmazsan geliştirme modunda konsola uyarı düşer.

```tsx
import { zodResolver } from "@hookform/resolvers/zod"
import { maskResolver, useViraMask } from "@virastack/mask"

const masks = { tckn: "tckn", phone: { preset: "phone", country: "TR" } } as const
const schema = z.object({ tckn: z.string().min(1, "required"), phone: z.string() })

const form = useForm({ resolver: maskResolver(masks, zodResolver(schema)) })
// ya da Standard Schema'yı doğrudan ver (@hookform/resolvers gerekmez)
const form2 = useForm({ resolver: maskResolver(masks, schema) })

const { tckn, phone } = useViraMask(form, masks)
```

Aynı şemayı sunucuda kullanmak için [sunucu](/mask/docs/server) sayfasına bak.
