<h2 id="prompt">Yapay zekâ ile tek adımda</h2>

Prompt'u kopyalayıp projende <AcademyBadge kind="claudeCode" />, <AcademyBadge kind="cursor" /> ya da <AcademyBadge kind="codex" /> gibi bir agent'a ver. Agent tüm kullanımları bulur, v2'ye çevirir, tip kontrolü ve testleri çalıştırır; sonunda biçimi değişen verileri (tarih ISO, TR IBAN'da `TR`) onayın için listeler.

<DocsPromptBlock prompt={MASK_UPGRADE_PROMPT} label="v1 → v2 upgrade prompt" copyLabel="Kopyala" />

Elle yapmak istersen aşağıdaki tablolar aynı adımları anlatır.

v1 dokümanı [arşivde](/mask/docs/v1) duruyor. Gereksinimler: <AcademyBadge kind="react" label="React 18.2+" />, <AcademyBadge kind="react-hook-form" label="React Hook Form 7.55+" />, <AcademyBadge kind="nodejs" label="Node 20+" />.

<h2 id="imza">Hook imzası</h2>

```tsx
- const { phone } = useViraMask({ form, schema: { phone: "phone" } })
+ const { phone } = useViraMask(form, { phone: { preset: "phone", country: "TR" } })
```

Şema anahtarları formdaki alan adları olmalı (ya da `name` ver). Yazım hatası artık derleme hatasıdır.

<h2 id="raw">rawValue kalktı</h2>

Form zaten ham değeri tutar. Dönen nesneyi doğrudan spread et.

```tsx
- const { rawValue, ...inputProps } = phone
- <input {...inputProps} />
+ <input {...phone} />
+ const raw = form.watch("phone") // "5551234567"
```

<h2 id="dogrulama">Resolver ile doğrulama</h2>

v1'de resolver varken maske doğrulaması sessizce duruyordu. v2'de resolver'ı sar:

```ts
useForm({ resolver: maskResolver(masks, zodResolver(schema)) })
```
