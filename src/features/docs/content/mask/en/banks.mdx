<h2 id="deneyin">Try it</h2>

Type an IBAN; the bank shows up as soon as the last digit of the bank code is in, and its row is highlighted in the table.

<MaskBankDemo />

<h2 id="nasil">How it works</h2>

A Turkish IBAN has 26 characters: `TR`, 2 check digits, a 5-digit bank code, 1 reserved digit and a 16-digit account number. The bank code is the CBRT (TCMB) participant code with a leading zero: `00062` in `TR63 0006 2…` is code `0062`, Garanti BBVA. So it works without a network call, the same in the browser and on the server.

The branch and the account holder cannot be read from an IBAN; only the banks' own services know them.

<h2 id="kullanim">Usage</h2>

```tsx
import { getTurkishBank, useViraMask } from "@virastack/mask"
import { useWatch } from "react-hook-form"

const { iban } = useViraMask(form, {
  iban: { preset: "iban", country: "TR" },
})
const bank = getTurkishBank(useWatch({ control: form.control, name: "iban" }))

<input {...iban} />
<p>{bank?.name}</p> // "T. GARANTİ BANKASI A.Ş."
```

```ts
import { getTurkishBank, turkishBanks } from "@virastack/mask"

getTurkishBank("TR63 0006 2000 0000 0000 1234 56")
// { code: "0062", name: "T. GARANTİ BANKASI A.Ş." }

getTurkishBank("TR63 0006 2")   // enough once the bank digits are typed
getTurkishBank("tr630006200000000000123456") // no spaces, lowercase
getTurkishBank("TR63 0006")     // null: bank code not complete yet
getTurkishBank("DE89 3704 0044 0532 0130 00") // null: not TR

turkishBanks.length // 70
```

`getTurkishBank` does not validate the IBAN itself; it names the bank of an IBAN with wrong check digits too. Use the `iban` preset or `isValidIBAN` for that. Both are on `@virastack/mask/server` as well.

The table is a plain array, so it stays out of apps that never use `getTurkishBank` or `turkishBanks`. When used, it adds about 2 KB.

<h2 id="kaynak">Source</h2>

The list comes from the payment systems participants table published by the [Central Bank of the Republic of Türkiye](https://www.tcmb.gov.tr/): 70 participants, last change 18.09.2026. Names are as TCMB writes them. When the list changes, a new package version updates it.
