Spread the returned object on the input. The component must pass `ref` to the real `<input>` (as a prop in <AcademyBadge kind="react" label="React 19" />, with `forwardRef` in<AcademyBadge kind="react" label="React 18" />). Don't pass `value`; the input is uncontrolled.

<h2 id="pattern">Shared pattern</h2>

```tsx
const { card } = useViraMask(form, { card: "card" })

// on screen: "4111 1111 1111 1111"
// form.watch("card"): "4111111111111111"

return <input {...card} placeholder="0000 0000 0000 0000" />
```

```tsx
// Need your own ref too? Call both
const inputRef = useRef<HTMLInputElement>(null)

<Input
  {...card}
  ref={(el) => {
    card.ref(el)
    inputRef.current = el
  }}
/>
```
