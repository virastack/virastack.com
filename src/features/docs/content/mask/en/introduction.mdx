<h2 id="neden">Why <GuideProductMark id="mask" linked={false} tone="heading">Mask</GuideProductMark>?</h2>

- **Built for <AcademyBadge kind="react-hook-form" />**: the form is the single source of truth; the hook keeps no value state.
- **Turkey ready**: TCKN, VKN, Turkish IBAN and phone, and TRY that keeps kuruş.
- **Type-safe**: field names, `from` and rules are checked against your form type; a typo is a compile error.
- **On the server too**: the same schema parses and validates in a Server Action with `@virastack/mask/server`.
- **Stays out of the way**: not a UI package; works with <AcademyBadge kind="shadcn" />, Radix or a plain input.

<h2 id="karsilastirma">Comparison</h2>

It doesn't compete with imask or Maskito on engine power; the difference is <AcademyBadge kind="react-hook-form" />, Turkey and the server.

The number is the gzip size of the difference over the same form built without a mask library, so <AcademyBadge kind="react" /> and <AcademyBadge kind="react-hook-form" />, present on both sides, are not counted.
