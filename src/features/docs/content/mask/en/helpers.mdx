All of them are pure and React-free. On the server, import them from `@virastack/mask/server`.

<h2 id="create-mask">createMask</h2>

The same object the hook uses. `format` for masked display in lists, tables and reports; `parse` for text from outside.

```ts
import { createMask } from "@virastack/mask"

const phone = createMask({ preset: "phone", country: "TR" })
phone.format("5551234567")        // "(555) 123 45 67"
phone.parse("+90 555 123 45 67")  // "5551234567"
phone.validate("555")             // "phone.incomplete"
phone.isComplete("5551234567")    // true

const price = createMask("currency")
price.format("1234.5", { from: "USD" }) // "$1,234.5"
```

<h2 id="validators">Validators</h2>

```ts
import {
  getCardType,
  isValidCard,
  isValidIBAN,
  isValidLuhn,
  isValidPlate,
  isValidTCKN,
  isValidVKN,
} from "@virastack/mask"

getCardType("3782 822463 10005") // "amex"
isValidCard("4111111111111111")  // true: length + Luhn
isValidTCKN("10000000146")       // true
isValidVKN("1234567890")         // true
isValidIBAN("DE89 3704 0044 0532 0130 00") // true, any country
isValidIBAN("TR330006100519786457841326")  // true
isValidIBAN("TR33000610051978645784132")   // false: a TR IBAN has 26 characters
isValidPlate("34 ABC 123")      // true: province 01–81 and the official groups
isValidPlate("34 AB 12")        // false: 2 letters need 3–4 digits
```

`isValidPlate` and the `plate` preset follow article 34 of the [Araçların Satış, Devir ve Tescil Hizmetlerinin Yürütülmesi Hakkında Yönetmelik](https://www.mevzuat.gov.tr/anasayfa/MevzuatFihristDetayIframe?MevzuatTur=7&MevzuatNo=24356&MevzuatTertip=5), Turkey's vehicle registration regulation: province code 01–81, then 1 letter and 4–5 digits, 2 letters and 3–4 digits, or 3 letters and 2–3 digits. The regulation excludes no Latin letter, so Q, W and X pass; Turkish letters don't. Name and trade-name plates (article 37) and special plates (article 36) are not checked.

To find the bank behind a Turkish IBAN, use [getTurkishBank](/mask/docs/banks). For valid TCKNs and IBANs in tests and seed data, see [test data](/mask/docs/testing).

<h2 id="money">Money</h2>

`toMinorUnits` turns a decimal string into integer minor units. The second argument is the number of fraction digits or an ISO currency code.

```ts
import { toMinorUnits } from "@virastack/mask"

toMinorUnits("1234.56", "TRY") // 123456
toMinorUnits("0.1", 2)         // 10 (no float errors)
toMinorUnits("1500", "JPY")    // 1500
```
