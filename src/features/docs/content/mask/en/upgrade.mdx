<h2 id="prompt">One step with an AI agent</h2>

Copy the prompt and give it to an agent such as <AcademyBadge kind="claudeCode" />, <AcademyBadge kind="cursor" /> or <AcademyBadge kind="codex" /> in your project. Prefer doing it by hand? The tables below describe the same steps.

The v1 docs are [archived](/mask/docs/v1). Requirements: <AcademyBadge kind="react" label="React 18.2+" />, <AcademyBadge kind="react-hook-form" label="React Hook Form 7.55+" />, <AcademyBadge kind="nodejs" label="Node 20+" />.

<h2 id="imza">Hook signature</h2>

```tsx
- const { phone } = useViraMask({ form, schema: { phone: "phone" } })
+ const { phone } = useViraMask(form, { phone: { preset: "phone", country: "TR" } })
```

Schema keys must be field names of your form (or set `name`). A typo is now a compile error.

<h2 id="raw">rawValue is gone</h2>

The form already holds the raw value. Spread the returned object directly.

```tsx
- const { rawValue, ...inputProps } = phone
- <input {...inputProps} />
+ <input {...phone} />
+ const raw = form.watch("phone") // "5551234567"
```

<h2 id="dogrulama">Validation with a resolver</h2>

In v1, mask validation silently stopped when a resolver was set. In v2, wrap the resolver:

```ts
useForm({ resolver: maskResolver(masks, zodResolver(schema)) })
```
