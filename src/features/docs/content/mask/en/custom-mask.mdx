<h2 id="dinamik">Dynamic masks</h2>

With an array, the first pattern that fits the whole value wins. A function gets the value and `ctx.from` (the linked field's value) and returns a pattern.

```tsx
useViraMask(form, {
  // the first pattern that fits wins
  code: { mask: ["999-999", "9999-9999"] },
  // pick the pattern from the value or a linked field
  card: {
    mask: (value) => (/^3[47]/.test(value) ? "9999 999999 99999" : "9999 9999 9999 9999"),
  },
  // clean the input before it is placed
  phone: { mask: "(999) 999 99 99", normalize: (value) => value.replace(/^0+/, "") },
})
```

<h2 id="sayi-tarih">Number, currency and date</h2>

`mask`, `number`, `currency` ve `date` exclude each other; passing two is a compile error.

- `number`: `min`, `max`, `scale` (fraction digits), `signed`, `locale` (default `en-US`; use the preset with `country: "TR"` for Turkish separators). Max applies while typing, min on blur. With `signed`, a negative max also applies on blur.
- `currency`: an ISO code or `{ code, locale, min, max, scale }`. Separators and symbol come from Intl. Without a code: `1,234.56`, no symbol; Turkish lira: `{ preset: "currency", country: "TR" }`.
- `date`: `format`, `min`, `max` (`"today"`, ISO or a `Date`), `minAge`. Full dates store ISO in the form.

<h2 id="preset">definePreset</h2>

Define your team's mask once. The name prefixes its error keys (`orderNo.incomplete`). The hook, the server and tests use the same object.

```tsx
// masks.ts — shared by the client and the server
import { definePreset } from "@virastack/mask/server"

export const orderNo = definePreset("orderNo", {
  mask: "aa-9999",
  transform: "uppercase",
  validate: (value) => !value.startsWith("XX") || "orderNo.reserved",
})

// form
useViraMask(form, { orderNo, returnNo: { preset: orderNo } })
```
